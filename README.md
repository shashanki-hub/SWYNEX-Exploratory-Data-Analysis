# SWYNEX Exploratory Data Analysis

## Project Overview
This project explores a cosmetics retail dataset as part of my internship at SWYNEX Technologies.

## Objectives
- Analyze product category and brand distributions.
- Compare estimated sales across categories and brands.
- Explore sales channels and product returns.
- Identify patterns, anomalies, and useful business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
1. Product category distribution
2. Estimated sales by product category
3. Top 10 brands by estimated sales
4. Records by sales channel
5. Returned vs. non-returned records
